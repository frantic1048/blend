# Blend website

The source for Blend's project website lives here. It is a static Astro site
with no client-side JavaScript or external styling framework.

- `/guide/` renders `../docs/GUIDE.md` directly; edit the guide there.
- `/changelog/` renders `../CHANGELOG.md` directly, with a release index;
  the Unreleased section is omitted from the rendered page.
  `/changelog.md` serves the same source as Markdown. Edit release notes in
  the root changelog. Changes to it also trigger Website CI.
- Code is highlighted at build time by Shiki with a custom theme
  (`src/shiki/coffee.ts`). Nickel uses the upstream TextMate grammar vendored
  in `src/shiki/nickel.tmLanguage.json`, patched by `src/shiki/nickel.ts`.
- Fonts in `public/fonts/` are Latin subsets of the Fraunces, EB Garamond, and
  JetBrains Mono variable fonts (SIL OFL 1.1, licenses alongside). They are
  stored with Git LFS; run `git lfs pull` if they appear as pointer files.
- `/guide.md` serves `../docs/GUIDE.md` verbatim. `public/llms.txt` links to it
  and to the other canonical documents rather than repeating them.
- `/.well-known/ard.json` serves the
  [Agentic Resource Discovery](https://agenticresourcediscovery.org/spec/)
  manifest defined in `src/discovery/ard.ts`, advertised by `rel="ard"` links
  and an `Agentmap` line in `public/robots.txt`. It lists only documents the
  site publishes. The build validates it against the vendored schema
  (`src/discovery/ard-entry.schema.json`) and fails if it is invalid.
  `public/_headers` sets the content types Cloudflare Pages serves.

## Brand assets

The wordmark, lockups, favicon, masthead SVG, social cards, and touch icon are
generated by `brand/build.py` from the site fonts and the spoon outline in
`brand/spoon.path`. The generated files are committed; the PNGs, like the
fonts, are stored with Git LFS. After changing the generator, run this from
this directory (it needs `uv` and `rsvg-convert`):

```sh
uv run --with fonttools --with brotli --with uharfbuzz python brand/build.py
```

The lockup's fog and glow are static SVG filters. The fog is drawn from soft
gradients, so it degrades gracefully where filters are unsupported, and under
forced colours the lockup becomes a single crisp colour.

## Development

From this directory:

```sh
pnpm install
pnpm dev
```

Before submitting changes, run:

```sh
pnpm check
pnpm build
```

The production output is written to `dist/`.

## Deployment

Website CI deploys `dist/` to Cloudflare Pages: pushes to `main` become the
production deployment and same-repository pull requests get preview
deployments. It reads the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`
secrets and the `CLOUDFLARE_PROJECT_NAME` variable.
